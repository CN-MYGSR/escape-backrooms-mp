# 后室：环形回廊 — Escape the Backrooms

一个零依赖资源、纯浏览器运行的第一人称 3D 后室逃脱游戏。
迷宫由 **BSP 二叉空间分割算法** 生成，并刻意凿出大量**环形回路**；潜行其中的有两种怪物：
**仿人类黑色实体「影者」**与**正面悬浮发光笑脸的黑色迷雾实体「笑靥」**。

## 运行方式

- **直接双击 `index.html`** 即可游玩（无模块、无网络请求，所有贴图与音效由代码实时生成）。
- 或起一个本地服务器：`python -m http.server 8137` → 访问 `http://localhost:8137/`。

推荐 Chrome / Edge，需要 WebGL。

## 玩法

| 按键 | 功能 |
|---|---|
| `WASD / 方向键` | 移动 |
| `鼠标` | 视角（点击画面锁定指针） |
| `Shift` | 奔跑（消耗体力） |
| `F` | 手电筒开关 |
| `Esc` | 暂停 |

开始界面设置：**阴影** 开关（性能弱可关）；**晕 3D 友好模式**（关闭视角摇晃、
FOV 冲刺拉伸与待机呼吸，鱼眼畸变强度减半）。

- 目标：在迷宫深处找到亮着绿色 **EXIT** 灯牌的门。- 迷宫中的金属电梯不是出口：进入后会到达有限的 **B1 停车场**，绿色 EXIT 出口已移动到停车场。
- B1 停车场怪物极少，但会出现伪装成玩家的伪装者，以及穿黄色重型防化服的搜救队；杏仁水和电池刷新较多。
- **杏仁水**（6 瓶）恢复体力与生命——但每一瓶都会让怪物永久提速。
- **理智（SAN）系统**：理智上限 100，每秒 -0.1（开局 3 秒宽限）。杏仁水每瓶 +40。
  - ≤75：移速下降 20%；
  - ≤50：随机听到自己的心跳声，画面畸变开始加重；
  - ≤25：随机出现**幻觉**——无 AI、不移动、不攻击、无碰撞的影者或笑靥，走近会消散；
  - 归零：死亡，你化作影者在倒下之处永远徘徊，游戏切换为**观战模式**（WASD 飞行、Space/C 升降、Shift 加速，自由观察怪物与你的"前身"）。
- **影者**：高约 2.5m 的黑色人形，BFS 寻路巡逻；进入它的视野（约 150°、30m）会被追猎，
  奔跑声也会引来它。被抓住会被击退并受重伤。
- **笑靥**：黑色粒子雾团，正面永远对着你显示一张发光笑脸。它能**缓慢穿墙**直线逼近；
  黑暗中有视线时大幅加速，**被手电筒照住时几乎停滞**——用它开路，或者绕开它。
- **导演系统**：两只会主动靠近——影者偏好在你附近的房间徘徊、每隔十几秒会隐约感知你的方位；
  任何一只离你太远太久（影者 38m / 笑靥 30m）都会被悄悄挪回到 10~20m 内的视野外，
  保证整局都有遭遇战。
- 没有小地图：出口只能靠**记忆与地标**寻找（出口门上方有发光的绿色 EXIT 灯牌，
  在 22m 内进入视线时会提示"远处透出绿光"）。
- 镜头表现：行走时有"八"字轨迹的视角摇晃（横向摆+纵向起伏+侧倾，奔跑更剧烈）；
  画面经由全屏鱼眼后期（桶形畸变 + 边缘色散）——畸变**常驻**，与怪物无关，理智越低越扭曲。

## 迷宫算法（BSP + 环形回路）

`js/maze.js`：

1. **BSP 递归切分**：63×63 网格（全部初始为墙），按长边随机切分为两个子区域，
   直到区域 ≤ 9×9（`maxLeaf`）成为叶子。切分位置取在偶数坐标上形成天然墙线。
2. **房间生成**：每个叶子内凿出一间奇数对齐的房间；大叶子有 26% 概率成为
   **立柱大厅**（整叶开放 + 网格立柱）。
3. **生成树连接**：后序遍历 BSP 树，每对兄弟子树各取靠分割线最近的房间凿一条 L 形走廊，
   得到完美迷宫（任意两点唯一路径）。
4. **环形回路**（关键需求）：
   - 在**已连通**的房间对之间额外凿走廊（`loopFactor × 房间数` 条），
     每条都会在生成树上产生一个真正的环——用"现有通路 > 曼哈顿距离+2 则跳过"保证不重复；
   - **死角编织（braiding）**：50% 概率把死胡同尽头打通，二次补环。
5. 安全网：BFS 验证所有房间连通，不通则硬凿；外墙强制保持完整。

实测每张图约 80~90 个房间、30+ 条凿出的环路（叠加房间/走廊交叉后全图有上千个可绕行回路）。

## 项目结构

```
index.html          入口与 UI 骨架
css/style.css       HUD / 全屏界面样式
js/lib/three.min.js Three.js r147（本地 UMD 版）
js/utils.js         种子随机数、数学、网格视线探测（DDA）
js/maze.js          BSP 迷宫生成器 + BFS 距离场/寻路
js/textures.js      程序化贴图（壁纸/地毯/吊顶/笑脸/EXIT/标签）
js/audio.js         WebAudio 程序化音效（电流嗡鸣/脚步/心跳/低语/惊吓…）
js/ui.js            HUD、战争迷雾小地图、消息、界面切换
js/player.js        第一人称控制、圆形碰撞、体力、手电筒
js/humanoid.js      怪物一「影者」：状态机 AI + BFS 巡逻/追猎
js/smiler.js        怪物二「笑靥」：粒子雾 + 广告牌笑脸，穿墙漂移
js/world.js         场景构建（实例化墙体/灯板/点光源池/出口门/杏仁水）
js/main.js          游戏状态机与主循环（含运行错误防护）
```

## 调参

主要数值集中在 `js/main.js` 的 `newRun()`（迷宫尺寸、回路密度、怪物出生距离）
与各怪物文件顶部附近的移动速度；`CELL = 3.2`、墙高 `WALL_H = 3.3` 在 `js/world.js`。

## 已知设计取舍

- 画面中央的长走廊与大面积房间是后室 Level 0 的风格，地图整体偏开放。
- 指针锁定在部分内嵌浏览器/iframe 中不可用时，可用按住鼠标拖动代替视角转动。
